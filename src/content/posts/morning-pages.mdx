I used to treat morning pages like a productivity stunt. Write three pages or the day was a failure. That version never lasted.

What stuck was smaller: a notebook, a timer, and permission to be boring. Some days it is grocery lists. Some days it is a half-formed argument about a book. The point is not brilliance. It is clearing the static before the inbox arrives.

If you miss a day, start again the next morning. The habit only works when it is allowed to be ordinary.
